# Stronger visual storytelling for the landing page

## Goal
Make the landing page feel like a premium civil-engineering product by showing the actual platform intent throughout the page, not only in the opening image.

## Changes
- Create a cohesive set of branded visuals for structural analysis, GIS/site context, compliance review, and permit documentation.
- Rework the capabilities area into varied editorial layouts with larger imagery, technical overlays, and clearer visual hierarchy.
- Add a product workflow graphic that connects plan ingestion, 3D generation, engineering analysis, and final documents.
- Add restrained engineering details such as coordinate markers, drawing annotations, status readouts, contour legends, and blueprint linework.
- Keep the existing warm drafting-paper, charcoal, steel, and safety-orange identity; preserve the current navigation, wording, and calls to action.
- Ensure all motion respects reduced-motion settings and all images include meaningful alternative text.

## Technical details
- Store generated imagery within the project and import it directly into the landing page.
- Use existing semantic color tokens and current motion patterns.
- Verify the page at desktop and mobile widths, checking image crops, text overlap, loading, and browser errors.
